# Strategic Command Center

Закрытая панель управления на Google Apps Script. Читает две существующие таблицы, ничего в них не меняет.
Три файла проекта: `Code.gs`, `Index.html`, `appsscript.json`.

## Развёртывание (пять действий, около пяти минут)

Автоматически развернуть не удалось: из среды разработки нет доступа к `script.google.com` и нет вашей авторизации.

1. Откройте проект Apps Script «Strategic command center».
2. Слева «Настройки проекта» → включите «Показывать файл манифеста appsscript.json в редакторе».
3. Замените содержимое трёх файлов содержимым из этой папки: `Code.gs`, `appsscript.json`; создайте файл «HTML» с именем `Index` (без расширения) и вставьте `Index.html`.
4. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение».
   Выполнять от имени: **Пользователь, открывающий веб-приложение**.
   Доступ: **Только я**.
   Разрешите доступ (только чтение таблиц и адрес почты).
5. Откройте выданную ссылку на iPhone и компьютере, войдите под своей учётной записью.

Часовой пояс в `appsscript.json` (`Asia/Yerevan`) поставлен как предположение. Он влияет только на то, какая дата считается «сегодня» при проверке сроков. Если нужен другой, измените.

## Проверка защиты

Откройте ссылку в приватном окне под другой учётной записью Google. Должен быть отказ Google ещё до загрузки панели. Если вместо этого что-то открылось, снимите развёртывание и напишите об этом.

## Что приложение читает и что не делает

- Читает: корпоративную и личную таблицы, только вкладки из списка в `Code.gs` (`SCC.CORPORATE_TABS`, `SCC.PERSONAL_TABS`). Исторические вкладки «Переговоры» и «Решения» не читаются.
- Контуры разделены: личные данные запрашиваются только при переключении на «Личный», корпоративные при этом выгружаются из памяти страницы.
- Права: `spreadsheets.readonly` и `userinfo.email`. Нет прав на Gmail, Календарь, Drive, отправку писем.
- Дополнительная проверка в коде: вызывающий должен быть владельцем таблицы (или перечислен в свойстве скрипта `OWNER_EMAIL`, через запятую). Если владелец не определился, доступ закрыт.

## Как читать метки достоверности

- Подтверждено: в таблице есть явная отметка («сверена», «утверждено», «действует» и т. п.).
- Требует проверки: «требует», «ожидает», «частично», «не подтверждён» и т. п.
- Цель / предположение: «цель», «шаблон».
- Нет данных: пусто, «неизвестно», «не определён», «не установлен».
- Просрочка объявляется только при указанной дате в прошлом у незакрытой записи.

Метки выводятся по словам в ячейках. Это эвристика, а не проверка по первоисточнику. Если формулировки в таблице изменятся, правила в `classify_` нужно подправить.

## Проверки

```
node --test tests/model.test.js                 # серверная логика, доступ, отсутствие записи
node tests/ui.test.js <каталог-снимков>         # интерфейс в Chromium (нужен Playwright)
```

Тесты используют фикстуры из реально прочитанной структуры; две строки (C06, R06) в них синтетические и помечены `SYNTH`.
