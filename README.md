# Hotel Performance Dashboard

Аналитическая панель пятизвёздочного отеля: загрузка, средняя цена номера, выручка на доступный номер (RevPAR), операционная прибыль; динамика по месяцам; сравнение факта с бюджетом и прошлым годом; загрузка данных из Excel. Интерфейс на русском, адаптирован под iPhone и компьютер, поддерживает тёмную тему.

Прототип работает на **вымышленных** демонстрационных данных. Платные сервисы не подключены, внешних библиотек и запросов в сеть нет, данные не покидают браузер.

## Запуск

```
npm start          # http://127.0.0.1:8080
```

Нужен только Node.js (проверено на 22). Зависимости ставить не нужно.

Один файл без сервера: `npm run build`, затем открыть `dist/hotel-dashboard.html`.

Для просмотра с iPhone в одной Wi-Fi-сети: `HOST=0.0.0.0 npm start` и открыть `http://<адрес-компьютера>:8080`. Сервер отдаёт данные без шифрования и защиты, не оставляйте его открытым в чужой сети.

## Формат Excel

Файл `.xlsx`, лист «Данные», одна строка = один месяц одного сценария:

| Год | Месяц | Сценарий | Доступно номеро-ночей | Продано номеро-ночей | Выручка от номеров | Общая выручка | Операционные расходы |

- Сценарий: «Факт», «Бюджет» или «Прошлый год» (данные того же месяца годом ранее).
- Месяц: число 1–12 или название. Месяцы без факта (ещё не закрыты) просто не добавляйте.
- Файл-пример со всеми данными демо скачивается кнопкой в окне загрузки.
- При ошибках файл не загружается, приложение показывает номера строк и причины (продано больше доступного, повтор, неверный сценарий и т. д.).
- Загруженные данные запоминаются в браузере (localStorage); сбросить можно кнопкой «Вернуть демо-данные».
- Старый формат `.xls` не поддерживается: сохраните как `.xlsx`.

## Формулы

- Загрузка = проданные ÷ доступные номеро-ночи
- Средняя цена номера = выручка от номеров ÷ проданные номеро-ночи
- RevPAR = выручка от номеров ÷ доступные номеро-ночи
- Операционная прибыль = общая выручка − операционные расходы (рабочее определение прототипа, нужно сверить с вашей методикой)

За несколько месяцев показатели считаются из сумм, а не средним по месяцам. Сравнение показывается, только если данные есть за все месяцы периода.

